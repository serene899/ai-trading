### 2. P0 修复：全新安装启动即崩
- 根因：旧 `requirements.txt` 不锁版本；2026-11 的 sqlmodel 0.0.50 拒绝 naive datetime 入库，
  而本项目存储约定是 naive UTC，`init_db` 创建初始账户时直接崩溃。
- 修复：① 时间列类型显式标注为 pydantic `NaiveDatetime`（存储语义不变，老数据零迁移）；
  ② `requirements.txt` 锁定实测版本组合；③ 顺手把已弃用的 `datetime.utcnow()` 换成等价新写法。
- 验证：全新 venv 按 `requirements.txt` 安装 → 服务启动、`/health` 返回 v1.1.0、测试 5/5 通过。

### 3. 补缺口
- **已实现盈亏落库**：`trade` 表新增 `realized_pnl` 列（老库启动时自动补列，幂等迁移）；
  卖出成交时按当时持仓均价计算 `(成交价 − 均价) × 数量 − 手续费` 落库；
  恒等式 总盈亏 = 已实现 + 未实现 在测试中逐步核对。
- **账户汇总**：`GET /api/v1/account` 新增 `realized_pnl`（成交流水加总）与 `total_fees`；
  总览页新增「已实现盈亏」「累计手续费」卡片；成交记录表新增「已实现盈亏」列。
- **行情来源标注**：总览与行情页标注「行情来源：OKX 公共行情」，分析面板带更新时间。
- **规则版 AI 分析**：新增 `GET /api/v1/analysis?symbol=BTC-USDT` 与行情页分析面板：
  MA5/MA20 趋势描述、1H 波动率与风险等级、持仓集中度/浮亏浮盈提示。
  全部本地规则计算，不接外部模型、无需 Key；接口与界面均带
  「仅供学习参考，不构成交易信号或投资建议」声明。
- **红线落实**：删除 config 与 .env.example 中从未被调用的交易所 API Key 字段，
  代码层面不再存在保存/读取真实 Key 的位置。

## 数据持久化说明

- 全部数据存后端 SQLite 文件 `backend/data.db`（被 .gitignore 排除，永不进仓库）：
  account（账户单行）、position（持仓）、order（订单）、trade（成交流水，含 fee 与 realized_pnl）、
  bot_config（机器人配置）、equitysnapshot（净值曲线）。
- 账户只在首次启动时初始化；重启、刷新都不会重置余额（已实测）。
- 备份 = 停服后拷贝 `data.db`；恢复 = 放回原路径重启。暂无自动备份机制（见已知问题）。

## 模拟账户操作说明

- 启动：`python run.py`（或分别启动后端 8000 / 前端 5173），浏览器打开前端地址。
- 买入 = 开仓/加仓（市价立即成交含 0.05% 滑点；限价挂单等价格触发）；卖出 = 平仓，
  卖出数量小于持仓即部分平仓，等于持仓即全部平仓。手续费 0.1% 双边收取。
- 总览页看总资产/现金/持仓市值/未实现/已实现/累计手续费与净值曲线；
  行情页下单并看规则版分析；订单页看订单与逐笔成交（含已实现盈亏）。
- 重置账户在总览页右上角（会清空持仓/订单/流水，谨慎使用）。

   待所有者拍板部署形态后按公网标准（HTTPS+登录+备份）补齐。

4. 机器人（DCA/网格/均线）沿用旧实现，本轮未做专项审计与测试。
5. 前端构建有大 chunk 体积警告（不影响功能）。

## v1.2.0 追补（2026-11-19，所有者拍板：按公网标准做）

- **登录验证**：单用户密码登录。密码存 PBKDF2-SHA256 哈希（环境变量），
  也支持 `AUTH_PASSWORD` 明文环境变量（仅内存哈希，方便手机上在云平台填变量部署）；
  会话为 HMAC 签名的 httpOnly Cookie（7 天）；登录失败 5 次锁 5 分钟。
  除 `/health` 与登录接口外，全部业务接口（含 config）未登录返回 401；前端新增登录页与退出登录。
- **Fail-closed**：`REQUIRE_AUTH=1` 且密码/密钥未配置时服务拒绝启动；本地未配置时为本地模式，
  启动日志与 `/health`、状态接口都会如实标注 `auth_enabled`。
- **单服务部署形态**：后端可托管 `frontend/dist`（已实测 `/`、SPA 路由、静态资源、API 共存正常），
  并提供多阶段 `Dockerfile`（数据卷 `/data`）。
- **测试**：新增 `backend/tests/test_auth.py`（含全流程子进程用例），全套 **10/10 通过**。
- **部署办法**：见 `docs/部署方案.md`。推荐路线 A：Render Starter $7/月 + 1GB 持久磁盘
  （免费版会休眠且数据不持久，不可用）；免费路线 B：Oracle Always Free（需信用卡验证、有容量与闲置回收坑）。
  实际开通账号与付费需所有者本人操作，Atlas 不代办。
